# 🌱 FloraTech Web - Plataforma de Monitoramento Inteligente

---

## 🚀 Sobre o Projeto

O **FloraTech Web** é a interface digital da solução FloraTech, desenvolvida para visualizar, analisar e gerenciar dados coletados por sensores em estufas inteligentes.

A plataforma permite acompanhar em tempo real as condições do ambiente, facilitando a tomada de decisões no cultivo.

---

## 🎯 Objetivo

Transformar dados brutos de sensores em informações visuais e úteis, proporcionando controle total sobre o ambiente da plantação.

---

## ⚙️ Funcionalidades

* 📊 Dashboard com dados em tempo real
* 🌡️ Monitoramento de temperatura
* 💧 Umidade do ambiente e do solo
* 💡 Luminosidade
* 🧪 Indicadores de pH 
* 📈 Gráficos interativos
* 📱 Layout responsivo

## 🧠 Como Funciona

1. O sistema recebe dados do hardware (ESP32)
2. Os dados são processados e organizados
3. O frontend exibe tudo em dashboards visuais
4. O usuário acompanha e toma decisões com base nas métricas
